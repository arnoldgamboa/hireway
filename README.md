# Hireway

Clickable **Nuxt 3** demo of the Hireway hiring loop (seed data only — no backend or auth).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use the **demo bar** to switch Public, Applicant, Client, and HR roles.

## Build

```bash
npm run build
npm run preview
```

## Product docs

Product requirements and UI screen map live in the project Agent Store (`docs/hireway-prd.md`, `docs/ui-screen-map.md`) and are not required to run this app.

## Demo tips

- **Reset demo** restores seed data from `data/seed.ts` (stored in `sessionStorage` until reset).
- Acceptance click-through is documented in the UI screen map.
